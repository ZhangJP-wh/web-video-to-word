# 网页视频转语音识别文字稿

**粘贴视频链接，后台识别语音，自动生成带时间戳的 Word 文稿。**

这是我的第一个 GitHub 项目。它来自一个日常需求：想读视频里的内容，却不想每次手动下载、上传、复制文字。本项目面向和我一样的电脑初学者，提供中文安装说明，也提供可以交给本地 AI Agent 阅读的完整指南。

目前主要面向 **Apple 芯片 Mac（M1、M2、M3 等）**。这是可运行的个人工具，还不是双击即装的商业软件。无需付费语音 API，也不需要 ChatGPT 账号。

## 使用后会得到什么？

1. 在本地页面粘贴 YouTube、B 站等受下载组件支持的视频链接。
2. 工具在后台下载音轨，调用 **Qwen3-ASR-1.7B** 本地模型识别。
3. 自动生成以视频标题命名的 Word 文件，包含原网页链接、时间范围和发言人编号。
4. 文档检查通过后，本次下载的媒体移入 Mac 废纸篓。
5. 在页面点击“查看 Word 文稿”或“打开文档所在位置”。

文档统一保存在：**下载 → 网页视频转语音识别文字稿**。任务记录按时间倒序排列，最新的在最上方。排队任务会提前获取网页标题，显示“待处理 · 视频标题”；获取失败时显示链接中的编号。

> 本文稿内容为语音模型识别结果，需要注意：可能有错别字和识别不准确之处。

文档不包含 AI 总结或自动纠错。时间戳是音频片段范围，不是逐字时间轴；多人编号由基础声纹聚类估计，可能分错，也不会识别真实姓名。

## 第一次安装：从这里开始

### 1. 确认电脑

点击 Mac 左上角苹果图标 → 关于本机。芯片应为 Apple M 系列。本版安装脚本要求原生 arm64 **Python 3.12**，以及 **Node.js 22 或以上的 LTS 版本**。

建议预留至少 **15GB** 空间；长视频还需要额外空间。模型约 4.4GB，首次下载可能较久。8GB 内存的原电脑可以运行，但速度可能慢。

### 2. 下载本项目

点击本页上方绿色 **Code** 按钮 → **Download ZIP**。双击 ZIP 解压，把解压得到的文件夹改名为 `VideoTranscript`，放到自己的“个人”目录。

“个人”目录可以通过 Finder 菜单“前往 → 个人”打开。以后不要随意移动装好依赖的整个文件夹。

### 3. 按详细指南安装

请先阅读 [安装与使用指南](INSTALL_GUIDE.md)，其中有 Python、Node.js 的官方下载链接、逐步安装说明、常见问题和验收方法。

已安装好 Python 3.12 和 Node.js 后，双击项目中的 **首次安装.command**。安装期间保持联网，等待显示“安装完成”。遇到系统安全提示时请按指南核查文件来源；不需要关闭系统安全保护。

也可以把 [INSTALL_GUIDE.md](INSTALL_GUIDE.md) 交给具有本机终端和文件权限的 AI Agent，请它按指南安装和测试。普通聊天机器人无法直接操作你的电脑；管理员密码、登录、验证码或系统授权仍可能需要本人处理。

### 4. 启动和使用

双击 **启动工具.command**，然后在浏览器打开：

**http://127.0.0.1:8767/**

这是你自己电脑上的页面，朋友需要在他们自己的电脑安装后才能访问。粘贴链接，点击“开始转写”，等待完成。确认页面打开后，启动用的终端窗口可以关闭；电脑需保持唤醒。


## 可选：登录自动启动和异常恢复

安装完成后双击 **启用自动启动.command**，看到成功提示后，macOS 会在你登录时自动启动工具，服务意外退出后自动重启。页面不会自动弹出，也不会操作鼠标。未完成任务按原顺序恢复；已完成和失败的任务不会自动重跑。

配置使用当前用户的 LaunchAgent，不需要管理员密码。请保留项目安装目录；停止自动启动、更新或卸载前，双击 **停用自动启动.command**。关闭服务不会强行结束已有语音识别子进程；更新依赖前请等待识别完成。详细操作和检查方法见 [安装指南第 7.1 节](INSTALL_GUIDE.md)。

电脑关机、未登录或休眠时仍可能无法访问。本功能恢复网页服务的意外退出，不保证所有模型和下载错误都能自行修复。

双击“自动恢复测试.command”可以实测异常恢复：脚本停止本工具的网页服务，等待最多 45 秒，检查新服务进程和原识别进程。结果保存到 work/recovery-test.json。测试只检查网页服务恢复，不模拟电脑重启，也不检查文稿准确率。

### 千问网页识别（实验性可选功能）

页面的识别方式可以选择“千问网页”。首次双击项目中的“配置千问登录.command”，安装官方 Playwright/Chromium 后，在工具专用浏览器中登录千问，回到终端按回车。登录资料保存在本机 work/qianwen-browser-profile，不上传 GitHub。后续任务使用无窗口浏览器，音频会上传千问服务器。

设置固定为中英文自由说、不翻译、多人讨论；只导出原文 Word，必须包含发言人和时间戳。导出后生成本项目格式的 Word，并执行原有文档检查和废纸篓清理。千问网页单文件上限为6小时，音频500MB；工具使用64kbps MP3上传。网站额度、验证码、登录失效、页面变化可能中断，此时保留原媒体并显示失败，不绕过验证码、不自动购买额度。

当前验证：已通过 Codex 隐藏浏览器完成20秒音频上传、转写和带发言人/时间戳的原文Word导出；真实导出解析与14项程序测试通过。**专用无窗口浏览器的完整流程尚未实测，不能视为已验证的全自动功能。**首次专用浏览器登录后，应先测试短视频再处理长视频。本地模型仍是默认选项，已有任务不自动切换。

## 常见问题

| 问题 | 说明 |
| --- | --- |
| 真的免费吗？ | 本工具与本地识别模型不按时长收费。电脑、电力、网络和视频网站会员不包含在内。 |
| 支持所有网页吗？ | 不保证。下载由 yt-dlp 完成，网站变更、地区限制、登录或验证码可能导致失败。 |
| 没有字幕也能识别吗？ | 可以，模型直接识别音频，不要求原视频有字幕。 |
| 会占用屏幕吗？ | 后台任务不操作鼠标、不切换桌面，但会占用 CPU、内存和磁盘。 |
| 准确率有多高？ | 不保证特定准确率。噪声、口音、专业词和同时讲话都可能影响结果，请对照原音频验收。 |
| 移入废纸篓后释放空间了吗？ | 没有，仍可恢复且仍占空间。工具不会自动清空废纸篓。 |
| Windows 或 Intel Mac 能安装吗？ | 本版安装流程暂不支持，需另外适配和验证。 |
| 安装后仍需要联网吗？ | 下载网页视频需要；本地识别使用缓存模型。 |

## 程序文件是什么？

| 文件 | 用途 |
| --- | --- |
| `首次安装.command` / `install.py` | 安装依赖、检查环境、下载模型 |
| `启动工具.command` | 启动本地后台服务 |
| `app.py` / `index.html` | 本地服务和中文页面 |
| `reader.py` | 下载、语音识别、发言人区分、Word 导出与清理 |
| `prefetch_model.py` | 提前下载模型和检查声音处理组件 |
| `requirements.txt` | 所需 Python 软件包 |
| `test_reader.py` / `test_app.py` | 程序自动测试 |
| `INSTALL_GUIDE.md` | 详细说明与完整源码附录，适合 AI 阅读 |

运行后生成的 `.venv` 是依赖环境；`work` 是任务记录、日志和模型缓存。这些内容不应上传到 GitHub。识别原始 JSON 会保留，便于恢复文档；原媒体只在文档写入检查通过后移入废纸篓。

## 验证与当前限制

分享副本已通过 14 项程序测试，并检查了脚本语法和指南源码完整性。测试中的语音识别使用模拟结果，不能证明真实听写准确率。原工具曾在 Apple M2、8GB 内存环境中做过真实短音频识别与文档生成；**还没有在另一台全新 Mac 上完成安装实测**。依赖并非全量锁定，未来版本变化可能需要维护。

请先按指南测试官方短音频，再测试自己能访问的短视频，最后处理长文件。使用自己有权访问与处理的音视频；不要上传 Cookie、个人文稿、视频或含私人链接的完整日志。

## 反馈问题和参与改进
