# Mac 独立浅色窗口

此可选窗口使用 macOS WKWebView，连接已有的 http://127.0.0.1:8767/ 后台服务，不依赖 Chrome PWA 外观。

先正常启动后台服务，再双击生成的“网页视频转语音识别文字稿.app”。支持复制粘贴、文件选择、拖放文件；按 Command-R 刷新。退出窗口不会停止后台服务。千问登录仍由原有专用浏览器处理。

应用、窗口和网页视图显式使用 Aqua 浅色外观。原生右键菜单实际表现仍需在使用者的 macOS 上验证；不要将编译通过表述成界面验收通过。

从源码构建：需要 Apple Command Line Tools，运行 `./build.command`。源码适用于 Mac，生成的二进制架构取决于构建机器。没有 Apple Developer ID 公证，首次启动可能需要系统允许打开。

当前只验证编译、Info.plist 和本地临时签名；上传、登录与完整处理需实际验收。原有 Chrome 入口保留，方便回退。

应用使用原有蓝底“视频转文稿”图标。WKWebView 空白处菜单可能只有重新加载；文字选择与输入框可使用 Command-C/V/X/A，浏览器扩展菜单不适用于这个窗口。

1.0.2 补充 WKWebView 的 JavaScript confirm 和 alert 原生对话框。删除任务必须点击确认后才发送请求；取消或关闭确认框不删除任务。更新后请退出并重新打开应用，网页后台无需重启。

1.0.3 增加原网页外部打开、Command-0 返回任务列表、Command-[ 返回上一页、文稿保存面板和连接失败提示。完整检查范围见功能检查记录.md。运行 `node test_ui.cjs` 可在模拟 API 下验证删除确认/取消、结果颜色与三秒提示，不操作真实任务。
